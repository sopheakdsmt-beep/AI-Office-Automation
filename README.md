## គោលការណ៍រចនាវគ្គ

វគ្គនេះសង់ឡើងលើគោលការណ៍ ៤៖

1. **សង់ ជាជាងស្តាប់** — ៤២% នៃពេលវេលាចំណាយលើការសង់ប្រព័ន្ធពិត
2. **មនុស្សអនុម័តជានិច្ច** — គ្រប់ Workflow មានជំហាន «មនុស្សពិនិត្យ» ច្បាស់លាស់
3. **ចាប់ផ្តើមតូច** — ការងារ ១ ដែលដដែលៗ · ច្បាប់ច្បាស់ · ហានិភ័យទាប
4. **ស្មោះលើដែនកំណត់** — យើងបង្រៀនអ្វីដែល AI **មិន** ធ្វើបាន ស្មើនឹងអ្វីដែលវាធ្វើបាន
