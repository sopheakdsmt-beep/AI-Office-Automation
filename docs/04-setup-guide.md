# ការតម្លើងប្រព័ន្ធ · Setup Guide

របៀបបំប្លែងឯកសារក្នុងឃ្លាំងនេះទៅជាវគ្គដែលដំណើរការពិត។
ដំណើរការទាំងអស់ប្រើ **Google Apps Script** ដែលឥតគិតថ្លៃ ហើយមិនត្រូវការ Server ទេ។

**ពេលវេលាសរុប:** ប្រហែល ៤៥ នាទី សម្រាប់លើកដំបូង។

- កម្មវិធីរុករក Chrome ឬ Edge
- មិនត្រូវការការដំឡើងកម្មវិធីអ្វីទាំងអស់

> **ចំណាំអំពីកូតា:** គណនី Gmail ធម្មតាផ្ញើបាន **១០០ អ៊ីមែល/ថ្ងៃ**។
> គណនី Google Workspace ផ្ញើបាន **១,៥០០ អ៊ីមែល/ថ្ងៃ**។

## ១. ទម្រង់ចុះឈ្មោះ · Registration form

**ឯកសារ:** `apps-script/1-registration-form.gs`
**ពេលវេលា:** ១០ នាទី

1. បើក <https://script.google.com> → **New project**
2. ប្តូរឈ្មោះគម្រោងទៅ `AIOA · Registration`
3. លុបកូដគំរូចេញ រួចបិទភ្ជាប់ឯកសារទាំងមូល
4. កែតម្លៃក្នុង `CONFIG` នៅផ្នែកខាងលើ៖

   ```javascript
   var CONFIG = {
     workshopDate:  '១៤ សីហា ២០២៦',
     workshopTime:  '១៩:០០ – ២០:០០ (ម៉ោងកម្ពុជា)',
     joinLink:      'https://zoom.us/j/…',      // ← តំណពិតរបស់អ្នក
     telegramGroup: 'https://t.me/…',
     replyTo:       'hello@yourdomain.com',
     seatLimit:     0                            // 0 = គ្មានកំណត់
   };
   ```

5. **Run** → ជ្រើស `buildRegistrationForm` → **Run**
6. Google នឹងសុំសិទ្ធិ៖ **Review permissions** → ជ្រើសគណនី →
   *Advanced* → *Go to … (unsafe)* → **Allow**

   > សារ «unsafe» លេចឡើងព្រោះស្គ្រីបនេះមិនបានឆ្លងកាត់ការត្រួតពិនិត្យរបស់ Google។
   > វាជារឿងធម្មតាសម្រាប់ស្គ្រីបដែលអ្នកសរសេរខ្លួនឯង។

7. បើក **Execution log** → ចម្លងតំណទាំង ៣៖ តំណចែក · តំណកែ · តារាងចម្លើយ

### ដំឡើងអ៊ីមែលបញ្ជាក់ស្វ័យប្រវត្តិ

ដើម្បីឲ្យ Trigger ចាប់បានត្រឹមត្រូវ សូមរត់វាចេញពី **ក្នុងទម្រង់** ៖

1. បើកតំណកែទម្រង់ (Edit URL)
2. ចុចរូបចំណុច ៣ (⋮) នៅជ្រុងខាងលើស្តាំ → **Script editor**
3. បិទភ្ជាប់ឯកសារដដែលចូលទីនោះ
4. **Run** → `installConfirmationTrigger`
5. សាកល្បងចុះឈ្មោះខ្លួនឯង ១ ដង → ពិនិត្យថាអ៊ីមែលមកដល់

### បន្ថែម (ស្រេចចិត្ត)

| មុខងារ | របៀបធ្វើ |
|---------|-----------|
| ផ្ញើការរំលឹកមុន ១ ថ្ងៃ | Run → `sendReminderToAll` |
| បិទស្វ័យប្រវត្តិពេលពេញ | កំណត់ `seatLimit` រួច Triggers → Add → `closeWhenFull` រៀងរាល់ម៉ោង |

## ២. តេស្តវាយតម្លៃ · Assessment quiz

**ឯកសារ:** `apps-script/2-assessment-quiz.gs`
**ពេលវេលា:** ១០ នាទី

1. គម្រោង Apps Script ថ្មី → ដាក់ឈ្មោះ `AIOA · Quiz`
2. បិទភ្ជាប់ឯកសារ → កែ `QUIZ_CONFIG`
3. **Run** → `buildAssessmentQuiz`
4. បើកតំណកែ → ⋮ → **Script editor** → បិទភ្ជាប់ឯកសារ →
   **Run** → `installQuizTrigger`
5. សាកល្បងធ្វើតេស្ត ១ ដង → ពិនិត្យ៖
   - អ៊ីមែលលទ្ធផលមកដល់?
   - សន្លឹក «លទ្ធផល · Results» លេចឡើងក្នុងតារាង?

### ការកែសំណួរ

សំណួរទាំងអស់ស្ថិតក្នុងអារេ `QUESTIONS` នៅផ្នែកខាងលើឯកសារ។

```javascript
{
  type: 'radio',              // 'radio' ចម្លើយ ១ · 'check' ចម្លើយច្រើន
  q: 'សំណួររបស់អ្នក?',
  options: ['ក', 'ខ', 'គ', 'ឃ'],
  correct: 1,                 // index ចាប់ពី 0 · អារេសម្រាប់ 'check'
  why: 'ការពន្យល់ដែលបង្ហាញក្រោយឆ្លើយ'
}
```

បន្ទាប់ពីកែ សូមរត់ `buildAssessmentQuiz` ម្តងទៀត (វាបង្កើតទម្រង់ថ្មី) —
ឬបើមានចម្លើយរួចហើយ សូមកែក្នុងទម្រង់ដោយផ្ទាល់ រួចរត់ `regradeAll`។

## ៣. វិញ្ញាបនបត្រ · Certificates

មាន **២ វិធី**។ ជ្រើសយកមួយ។

### វិធី ក · បង្កើតក្នុងកម្មវិធីរុករក (ងាយបំផុត)

សម្រាប់វគ្គតូច ឬពេលអ្នកចង់គ្រប់គ្រងរូបរាងច្បាស់លាស់។

1. បើក `certificate/index.html` ក្នុង Chrome
2. បំពេញព័ត៌មាន ឬបិទភ្ជាប់បញ្ជីឈ្មោះក្នុងប្រអប់ «បញ្ជីឈ្មោះច្រើននាក់»៖

   ```
   Sok Dara, សុខ តារា, DSMT-AIOA-2026-0001, 14/15 · 93%
   Chan Nita, ចាន់ នីតា, DSMT-AIOA-2026-0002, 15/15 · 100%
   ```

3. ចុច **បង្កើតវិញ្ញាបនបត្រ** → **បោះពុម្ព / រក្សាទុកជា PDF**
4. ក្នុងប្រអប់ Print៖ **A4 · Landscape · Margins: None · Background graphics ✓**

### វិធី ខ · បង្កើត និងផ្ញើដោយស្វ័យប្រវត្តិ

សម្រាប់វគ្គធំ ដែលអ្នកមិនចង់ផ្ញើម្នាក់ម្តងៗ។

**ឯកសារ:** `apps-script/3-certificate-mailer.gs`

1. បើក **តារាងចម្លើយរបស់តេស្ត** (ដែលមានសន្លឹក «លទ្ធផល · Results»)
2. **Extensions → Apps Script**
3. បិទភ្ជាប់ឯកសារ → កែ `CERT_CONFIG`
4. **សាកល្បងជាមុនសិន:** Run → `previewOneCertificate`
   → បើកតំណក្នុង Log ដើម្បីមើល PDF
5. ពេញចិត្តហើយ → Run → `issueAllPending`

> **ការការពារ:** ដាក់ `dryRun: true` ដើម្បីបង្កើត PDF ដោយ **មិនផ្ញើអ៊ីមែល**។
> ពិនិត្យលទ្ធផលក្នុង Drive ជាមុន រួចប្តូរទៅ `false` ទើបផ្ញើពិត។

ស្គ្រីបនេះ **មិនផ្ញើស្ទួន** ទេ — វាចងចាំអ៊ីមែលដែលបានផ្ញើរួចក្នុងសន្លឹក
«វិញ្ញាបនបត្រ · Certificates»។ ដូច្នេះអ្នករត់វាម្តងទៀតបានដោយសុវត្ថិភាព
ក្រោយពីមានអ្នកធ្វើតេស្តបន្ថែម។

## ៨. សុវត្ថិភាព និងឯកជនភាព

ស្គ្រីបទាំងអស់រត់ក្រោមគណនី Google **របស់អ្នក** ហើយទិន្នន័យស្ថិតនៅក្នុង
Drive របស់អ្នកតែប៉ុណ្ណោះ។ គ្មានទិន្នន័យផ្ញើទៅភាគីទីបីទេ។

**ការណែនាំ:**

- ប្រើគណនីអង្គភាពសម្រាប់ការបណ្តុះបណ្តាល មិនមែនគណនីផ្ទាល់ខ្លួន
- លុបទិន្នន័យអ្នកចុះឈ្មោះក្រោយពីផ្ញើវិញ្ញាបនបត្ររួច បើអ្នកមិនត្រូវការទៀត
- ទម្រង់មតិយោបល់មិនប្រមូលអ៊ីមែលទេ (ដោយចេតនា) — ដើម្បីទទួលចម្លើយត្រង់
- បើអ្នកចែករំលែកតារាងចម្លើយ សូមប្រើសិទ្ធិ «អាចមើលបាន» មិនមែន «អាចកែបាន»
