# ឯកសារសម្រាប់អ្នកចូលរួម · Participant Handout
## AI for Office Automation — ការងារ ៨ ម៉ោង សល់ត្រឹម ២ ម៉ោង

> បោះពុម្ព ២ ទំព័រ ឬបើកក្នុងទូរស័ព្ទពេលរៀន។
> កន្លែងទំនេរគឺសម្រាប់អ្នកសរសេរ — កុំគ្រាន់តែអាន។

---

## ១. ពាក្យ ៣ ដែលត្រូវយល់ឲ្យច្បាស់

| ពាក្យ | មានន័យថា | ឧទាហរណ៍ | អ្នកនៅតែត្រូវអង្គុយធ្វើ? |
|-------|----------|----------|---------------------------|
| **AI** | អ្នកសួរ វាឆ្លើយ | Copy អត្ថបទចូល ChatGPT «សង្ខេបឲ្យខ្ញុំ» | ✅ បាទ/ចាស — រាល់ដង |
| **AI Agent** | មានឧបករណ៍ ធ្វើជាជំហានៗ | ដកទិន្នន័យពី Invoice → ពិនិត្យ → រៀបជាតារាង | ⚠️ អ្នកចាប់ផ្តើម វាបន្ត |
| **AI Automation** | មាន Trigger ចាប់ផ្តើមខ្លួនឯង | Email ចូល → AI ព្រាងចម្លើយ → Telegram សុំអនុម័ត | ❌ ទេ — វាដើរដោយខ្លួនឯង |

> **ចំណុចសំខាន់៖** AI ដែលគ្មាន Automation នៅតែស៊ីម៉ោងរបស់អ្នក។

## ២. រូបមន្ត Prompt · R · T · C · F

| អក្សរ | មានន័យ | ឧទាហរណ៍ |
|-------|--------|----------|
| **R** — Role | វាជានរណា? | «អ្នកជាជំនួយការរដ្ឋបាលបទពិសោធន៍ ១០ ឆ្នាំ» |
| **T** — Task | ធ្វើអ្វី? (តែមួយ) | «សង្ខេប Email នេះជា ៣ ចំណុច» |
| **C** — Context | ទិន្នន័យ និងច្បាប់ | «អតិថិជនចាស់ · សំឡេងផ្លូវការ · ជាភាសាខ្មែរ» |
| **F** — Format | លទ្ធផលរាងបែបណា? | «JSON មាន key: urgency, deadline, summary» |

**F ជាចំណុចដែលមនុស្សភ្លេចច្រើនបំផុត** — ហើយវាជាចំណុចដែលធ្វើឲ្យ Automation ដំណើរការ។

### សរសេរ Prompt របស់អ្នកនៅទីនេះ

```
Role:    ________________________________________________

Task:    ________________________________________________

Context: ________________________________________________

Format:  ________________________________________________
```

### គន្លឹះ ៣ ដែលប្រើបានភ្លាម

1. ដាក់ទិន្នន័យក្នុងសញ្ញា `"""` ដើម្បីបំបែកវាចេញពីបញ្ជា
2. បន្ថែមឃ្លា «បើមិនច្បាស់ សូមសរសេរថាមិនច្បាស់ — ហាមទាយ»
3. សុំ ២ ជម្រើសជានិច្ច — ជ្រើសលឿនជាងកែសម្រួល

## ៣. តេស្ត ៤ សំណួរ — មុននឹងសង់អ្វីមួយ

សរសេរការងាររបស់អ្នក៖ ______________________________________

| # | សំណួរ | ចម្លើយ |
|---|-------|--------|
| ១ | តើវាកើតឡើងដដែលៗទេ? (យ៉ាងតិច ១ដង/សប្តាហ៍) | ☐ បាទ/ចាស ☐ ទេ |
| ២ | តើមានច្បាប់ច្បាស់លាស់ទេ? (ពន្យល់បុគ្គលិកថ្មីក្នុង ៥ នាទី) | ☐ បាទ/ចាស ☐ ទេ |
| ៣ | តើទិន្នន័យស្ថិតក្នុងកន្លែងឌីជីថលទេ? | ☐ បាទ/ចាស ☐ ទេ |
| ៤ | បើវាធ្វើខុស តើប៉ះពាល់ធ្ងន់ធ្ងរប៉ុណ្ណា? | ☐ ទាប ☐ មធ្យម ☐ ខ្ពស់ |

**ការបកស្រាយ:**
- ឆ្លើយ «បាទ/ចាស» ៣ ដំបូង + ហានិភ័យទាប → **ចាប់ផ្តើមភ្លាម** ✅
- ឆ្លើយ «បាទ/ចាស» ៣ ដំបូង + ហានិភ័យខ្ពស់ → សង់បាន **តែត្រូវមានមនុស្សអនុម័តជាដាច់ខាត** ⚠️
- ឆ្លើយ «ទេ» ២ ឬច្រើនជាង → **កុំទាន់** — ជ្រើសការងារផ្សេង ❌

## ៥. ៥ ជំហានសង់ប្រព័ន្ធដំបូង

- [ ] **១.** បង្កើត Google Sheet ១ ជាកន្លែងទទួលទិន្នន័យ — ដាក់ចំណងជើងជួរឈរឲ្យច្បាស់
- [ ] **២.** កំណត់ Trigger — Email ចូល · Form បញ្ជូន · ឬម៉ោងកំណត់
- [ ] **៣.** ដាក់ Prompt (R·T·C·F) ហើយបង្ខំឲ្យចេញជា JSON
- [ ] **៤.** បន្ថែមជំហានមនុស្សអនុម័ត — Telegram ឬ Email
- [ ] **៥.** សាកល្បង ៣ ដង៖ ករណីធម្មតា ១ · ករណីចម្លែក ១ · ករណីខូច ១

## ៦. អ្វីដែល AI ធ្វើបានល្អ និងមិនបាន

| ✅ ធ្វើបានល្អ | ❌ មិនទាន់បាន |
|---------------|----------------|
| សង្ខេប · បកប្រែ · រៀបរចនាសម្ព័ន្ធ | ធានាលេខគណនេយ្យ ១០០% |
| ដកទិន្នន័យពីឯកសារមិនរៀបរយ | ដឹងបរិបទក្រុមហ៊ុនដែលមិនបានប្រាប់ |
| ចាត់ថ្នាក់ · តម្រៀបតាមប្រភេទ | ទទួលខុសត្រូវលើការសម្រេចចិត្ត |
| សរសេរសេចក្តីព្រាងលើកទី១ | ដឹងថាខ្លួនវាឆ្លើយខុស |

> **ច្បាប់មាស៖ AI សរសេរសេចក្តីព្រាង — មនុស្សចុចអនុម័ត។**

## ៧. សុវត្ថិភាព — ៥ ច្បាប់មុនប្រើពិត

1. **ចាប់ផ្តើមក្នុងរបៀបព្រាងជានិច្ច** — ២ សប្តាហ៍ដំបូង៖ AI ព្រាង មនុស្សផ្ញើ
2. **កុំដាក់ទិន្នន័យរសើបចូល AI សាធារណៈ** — លេខអត្តសញ្ញាណប័ណ្ណ · គណនីធនាគារ · ប្រាក់ខែ · កិច្ចសន្យាសម្ងាត់
3. **រក្សាកំណត់ហេតុគ្រប់ដំណើរការ** — Sheet ១ សន្លឹក៖ ពេលណា · ធ្វើអ្វី · លទ្ធផលអ្វី
4. **មានប៊ូតុងបិទបន្ទាន់** — ត្រូវដឹងច្បាស់ថាបិទយ៉ាងណាក្នុង ១០ វិនាទី
5. **ប្រាប់ក្រុមការងារ និងចៅហ្វាយជាមុន** — Automation ដែលគេមិនដឹង = បញ្ហាទំនុកចិត្ត

## ៨. គំរូ Prompt ត្រៀមប្រើ ២

### ក. សង្ខេប Email + ដកសកម្មភាព

```
Role: អ្នកគឺជាជំនួយការរដ្ឋបាលដែលមានបទពិសោធន៍ ១០ ឆ្នាំ។

Task: អាន Email ខាងក្រោម រួចសង្ខេបជាចំណុចសំខាន់ ៣
ហើយប្រាប់ខ្ញុំថាតើខ្ញុំត្រូវធ្វើអ្វីបន្ទាប់។

Context: ខ្ញុំធ្វើការនៅ [ក្រុមហ៊ុន] ក្នុងតួនាទី [តួនាទី]។

Format:
• សង្ខេប៖ ៣ ចំណុច មិនលើស ២០ ពាក្យក្នុងមួយចំណុច
• សកម្មភាពត្រូវធ្វើ៖ បញ្ជីខ្លីៗ
• កាលបរិច្ឆេទកំណត់៖ បើមាន
• កម្រិតបន្ទាន់៖ ខ្ពស់ / ធម្មតា / ទាប

Email:
"""
[ដាក់អត្ថបទនៅទីនេះ]
"""
```

### ខ. ដកទិន្នន័យចេញជា JSON (សម្រាប់ Automation)

```
Role: អ្នកគឺជាប្រព័ន្ធដកទិន្នន័យ។ អ្នកឆ្លើយតែជា JSON។

Task: ដកទិន្នន័យចេញពីឯកសារខាងក្រោម។

Format: JSON តែប៉ុណ្ណោះ។ បើរកមិនឃើញ សូមដាក់ null — ហាមប្រឌិត។
{
  "doc_number": null,
  "issue_date": "YYYY-MM-DD",
  "vendor": null,
  "total": 0,
  "confidence": "high|medium|low",
  "needs_human_review": true|false
}

ឯកសារ:
"""
[អត្ថបទ]
"""
```

> Prompt ទាំង ៥០+ មាននៅក្នុង **Prompt Library** — តំណនៅចុងវគ្គ។
